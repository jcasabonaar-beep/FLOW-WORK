# Lecciones aprendidas (los trabajadores leen esto antes de empezar y lo amplían)

- Flow rechaza ("might violate our policies") cualquier generación que use una imagen de una persona real que no sea nuestra avatar. Nunca subir capturas del reel de referencia: describir la pose con palabras.
- Mencionar el tono de piel / color de piel junto a una foto de persona provoca rechazos. No mencionarlo nunca.
- Un prompt corto con solo la foto de la avatar ("The same woman in the same kitchen, smiling at the camera and holding a white ceramic mug with both hands. Vertical 9:16, natural smartphone photo.") funciona siempre: es la base segura para ir añadiendo detalles.
- Comprobar que las imágenes quedan ADJUNTAS a la caja del prompt (miniatura visible) antes de generar; si no, Flow genera otra persona.
- El proyecto de Flow se sincroniza con el otro Chrome del productor: si aparecen cosas que no hiciste, ignóralas.
- Descargar desde la cuadrícula del proyecto: ⋮ (tres puntos) de cada tarjeta → Download → 720p en videos. No abrir cada clip: se pierde mucho tiempo.
